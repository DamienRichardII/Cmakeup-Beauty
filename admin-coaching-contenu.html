Comment ça marche : choisis la page, puis modifie les textes dans les cases (les blocs sont rangés par section de la page). Une case laissée vide garde le texte d'origine. Clique sur « Enregistrer les modifications » en bas : c'est en ligne tout de suite.
Un prix apparaît à plusieurs endroits (offre, tableau comparatif, « Quelle offre pour toi ? », déroulé, FAQ, page de réservation) : utilise la recherche ci-dessous (par exemple « 150 ») pour retrouver chaque endroit à mettre à jour.
À noter : les montants réellement encaissés (Calendly / Stripe) se règlent dans ces outils, pas ici. Modifier le texte d'une question ne change pas le nom de la colonne dans les demandes reçues.
